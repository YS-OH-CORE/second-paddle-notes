# Publication queue

This file prevents the repository from becoming an undifferentiated archive. A note moves to `notes/` only when its direct source, claim boundary, and testable use are clear.

## Ready for editorial review

1. **The Observer Cannot Be Passive**  
   A conversational model cannot be observed without input changing the next output. Design matched intervention and replay conditions instead of calling an ordinary chat “passive observation.”

2. **Core Signal or User-Matched Performance?**  
   Distinguish a model-specific stable behavior from compliance, persona, and narrative adaptation by changing the user framing while preserving the task structure.

3. **Check the Source Before Matching the Mood**  
   Personalization should retrieve and compare the user's original evidence before producing a socially smooth guess.

4. **Where Is the Control Group?**  
   Internal coherence is not external validity. Convert the user's own doubt into matched baselines, blinding, perturbation, and negative controls.

5. **From Prompt to World**  
   Separate language quality from the verified external effect of a computer-using agent.

6. **Teach the Forge, Not the Sword**  
   Measure whether an assistant leaves a user with a reusable method for inquiry rather than a one-off answer.

## Design rule

Each queued note must contain:

- a direct Youngseok-authored signal,
- a public-safe source date or identifier,
- an editorial interpretation clearly marked as such,
- one falsifiable hypothesis,
- one minimum viable test,
- one explicit statement of what the test would not prove,
- links to primary related work where relevant.

No scheduled bulk posting. Publication is a reviewed state transition, not a heartbeat.
