# One-shot public form read

Isolated operational snapshot for a public-source reader. Not a merge candidate.
The repository default branch, research, private notes and user records are unchanged.
The only workload is a bounded, anonymous browser read of the public Foresight call
and up to two application links, with the historical public form as a labeled fallback.
No applicant answers, credentials, correspondence, identity documents or submissions.
No form interaction; non-read requests are blocked. Only public observations go to logs.
A standard public Ubuntu runner is used; no artifact uploads, caches, external AI API,
large runners, scheduled jobs, or persistent service. Maximum job runtime: five minutes.
