# 같은 입력인데 다르게 판단해야 하는 상황을 찾는 도구

**Handoff Audit 0.1 · 영석 × 제로 · 2026년 9월 28일**

이전 연구 설명문에서 제안했던 ‘정보가 도착하기 전에 중요한 구별이 사라졌는가?’를 검사하는 작은 프로그램이다. 추가 설치나 모델 호출 없이 실행한다. 영석의 실제 기억 자료는 읽거나 공개하지 않았다.

## 무엇이 달라졌나

가령 사용자가 승인한 변경과 제로가 제안만 한 내용을 모두 `B를 쓰자`라는 한 문장으로 줄였다고 하자. 다음 판단에는 승인 여부가 필요하지만, 그 문장만 받은 쪽에서는 구별할 수 없다. 원문을 다시 찾아볼 수 있다면 달라지므로, 이 도구는 **판단할 때 실제로 이용할 수 있는 정보가 어디까지인지**를 입력에 명시하게 한다.

도구는 같은 요청과 같은 정보를 받은 기록들을 묶고, 그 모두에서 받아들일 수 있는 행동이 하나라도 있는지 확인한다. 받아들일 행동이 없는 묶음은 원래 사례의 번호와 함께 보고한다. 답의 정당성과 원문의 차이를 검토하는 일은 여전히 입력을 만든 사람의 책임이다.

여기서 ‘충돌’은 환각이나 새 아이디어에 붙이는 이름이 아니다. **주어진 정보로는 서로 다른 요구를 동시에 만족시킬 수 없는 입력 묶음**을 뜻한다.

## 실제 코드를 대상으로 확인한 예

이미 검토한 vLLM의 Mistral 호환 처리 함수를 원래 코드 그대로 꺼내 실행했다. 두 도구가 두 사진을 반환하는 네 가지 가상 기록을 만들고, 사진 Y의 출처를 물었다. 모델이나 실제 사진은 사용하지 않았다.

| 전달된 정보 | 확인 결과 |
|---|---|
| 이미지를 원래 도구 응답에 두는 경로 | 네 기록이 구별됨 |
| 구형 호환 처리 뒤 메시지만 전달 | 네 기록 중 세 개가 같은 입력으로 합쳐지고, 필요한 출처 답은 서로 달랐음 |
| 호환 처리된 메시지에 출처 표를 별도로 제공 | 다시 구별됨. 실제 서버 수정안이 아니라 대조용 정보임 |
| 출처 답 대신 ‘원래 결과를 다시 확인하자’도 허용 | 공통의 다음 행동이 생김. 출처를 알아냈다는 뜻은 아님 |

마지막 구별이 중요하다. **같은 정보라고 언제나 막힌 것은 아니다. 두 경우 모두 추가 확인이 허용되면 그다음 행동은 가능하다.** 도구가 임의로 ‘질문하면 되지’라는 정답을 끼워 넣지는 않으며, 해당 과제에서 그것이 허용되는지 직접 지정해야 한다.

영문 결과의 `3/4`는 이 네 가지 가상 기록을 같은 비중으로 보고 반드시 출처를 바로 답해야 한다는 조건의 계산값이다. 어떤 모델의 정확도나 현실 서비스의 상한을 측정한 것이 아니다. 최신 Mistral이나 vLLM 전체의 문제라고 새로 신고하지 않았다.

## 실행 방법

Python이 있는 환경에서 이 폴더를 기준으로 실행한다. 형의 PC에서 지금 실행할 필요는 없다.

```sh
python -B -m unittest -v test_audit
python -B demo.py
python -B audit.py example.json
```

첫 명령은 도구 검사를, 두 번째는 네 가상 기록에 대한 대조를 실행한다. 세 번째 예제는 일부러 충돌이 있는 자료이므로 종료 코드 1이 맞다. 0은 제공된 자료에서 충돌을 못 찾았다는 뜻, 2는 입력 또는 파일 처리 문제다. 기존 파일은 덮어쓰지 않는다.

실제 검사에서는 예상 사례 번호 목록과 결과 목록을 맞추므로, 사례 하나가 빠진 상태를 성공으로 보고하지 않는다. 다만 예상 목록 자체에 처음부터 빠진 사례까지 알아내지는 못한다. 요청 내용, 출처 표 등 실제로 모델이 볼 추가 상태를 누락하면 결론도 잘못될 수 있다.

27개 소프트웨어 검사가 통과했고, 그중 하나는 작은 행동·정보 조합 3,430개에서 가능한 모든 선택을 직접 나열해 계산을 대조했다. **모델 실험 수가 아니다.** 실제 기억 시스템 개선이나 외부 채택까지 완료했다는 주장도 하지 않는다.

## 이 작업의 범위

이번에 만든 것은 여러 기록에서 구별 불가능해진 판단 조건을 찾는 재사용 가능한 검사다. 기존 연구 설명문을 실행 가능한 도구로 옮긴 것이며, 새 일반 이론이나 AGI를 입증한 실험은 아니다. 읽기·추론·실제 실행은 별도로 검사해야 한다.

영석은 질문과 방향을, 제로는 구현·검사·기록을 맡았다. 사용한 vLLM 함수의 기여와 저작권은 원래 개발자들에게 남긴다. 사용자 PC·비공개 기억·유료 API·외부 프로젝트의 글은 건드리지 않았다.
