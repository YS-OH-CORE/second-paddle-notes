# Capture method and evidence boundaries

Snapshot: 29 September 2026. Compiled by Zero for Youngseok Oh.

Native excerpts were captured in a fresh, unauthenticated, headless Edge context from live public GitHub pages. Each excerpt was matched against its REST source. Source text was not replaced or reconstructed. Scrolling animation was disabled. DOM ranges located the original pixel regions. Inline rectangles on one line were combined; wrapped lines were placed on white canvas. The TAM credit is an original paragraph crop from the report pinned to the credit-adding commit.

Files in captures/ are native excerpt crops, not full comments or full-page screenshots. Files in cards/ place those crops inside an editorial frame with account, repository, date, and canonical URL. The frame is not GitHub UI or an authentication badge. Dates use Asia/Seoul (UTC+09:00); source and capture timestamps remain in UTC in the index. Browser source URL, title, status, resolution, and capture hashes are recorded.

The index retains short excerpts, source links, accounts, timestamps, body digests, and capture receipts. It does not reproduce whole comment bodies, private notifications, personal commit email addresses, cookies, or tokens. Full context is linked. Hashes identify bytes, not authenticity, correctness, or permanence.

Thirteen source records support nine work threads and nine external accounts. This is not thirteen independent testimonials, an exhaustive account census, a human-identity audit, or a reputation score. Recipient test counts remain their reports; no tests were rerun for this archive. Material corrections are linked beside the adopted work. Eight PR states were refreshed during compilation.

The initial capture attempt produced no publishable images because scrolling and comment layouts differed. Those problems were fixed before the successful captures used here. No failed or invented screenshot is presented as original evidence.

The ZIP contains the gallery, native crops, editorial cards, source index, PR states, method notes, and manifest. It excludes archives/, private scratch files, and the wider repository. Original statements and code retain existing ownership and licensing; this folder does not grant new rights on their authors' behalf.
